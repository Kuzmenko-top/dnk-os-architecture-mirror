# 🎯 Intent: Live Bidirectional Visual-to-Code Synthesizer (Canvas Engine MVP)

## 📋 Metadata
- **Intent ID**: `INTENT-20260903-001`
- **Originator**: `Maxim (Lead Architect & Founder)`
- **Mentor / Quality Gate**: `Antigravity (Mentor & Head of Orchestration)`
- **Assigned Worker**: `Gerych Swarm (Builder & Subagents in .worktrees/task-canvas-live-compiler)`
- **Domain / Bounded Context**: `apps/visual_shell`, `services/dnk_canvas_api`
- **Target Release**: `DNK OS MVP`
- **Status**: `Approved`

---

## 💡 1. Problem Statement & Core Business Value
- **Current Bottleneck**:
  Visual Shell ([StitchCanvasContainer.tsx](../../visual_shell/open_design/apps/web/src/components/stitch/StitchCanvasContainer.tsx)) displays interactive elements and nodes on an infinite canvas, but lacks an instantaneous bidirectional bridge to production code. When an operator places or edits UI sections (Hero, Product Grid, Checkout Banner, Analytics Card), they currently have to manually write or reconstruct the React TSX and Tailwind styling.
- **Expected Outcome**:
  When elements are selected, moved, or updated on the Canvas, `services/dnk_canvas_api/compiler` translates the canvas scene AST on-the-fly into clean, modular, production-ready **React TSX + Tailwind CSS v4** code. The code is displayed in [StitchSmartInspector.tsx](../../visual_shell/open_design/apps/web/src/components/stitch/StitchSmartInspector.tsx) with syntax formatting and one-click copy/export.
- **Measurable Value Metric**:
  - AST compilation latency `< 200ms`.
  - 100% syntactically valid TypeScript/React code without undefined references.

---

## 🗺️ 2. Bounded Context & Affected Services
- **Backend**:
  - `services/dnk_canvas_api/compiler/visual_to_code_synthesizer.py`: The deterministic compiler engine transforming Canvas elements to React TSX + Tailwind.
  - `services/dnk_canvas_api/main.py`: Expose `POST /api/v1/canvas/synthesize` endpoint.
  - `services/dnk_canvas_api/tests/test_visual_to_code.py`: Unit test suite verifying synthesis of Hero, Grid, Form, and Container nodes.
- **Frontend**:
  - `visual_shell/open_design/apps/web/src/components/stitch/StitchSmartInspector.tsx`: Add "Live Code" tab with real-time fetch from `/api/v1/canvas/synthesize` and copy-to-clipboard action.

- ❌ **No Test Tampering**: Anti-Tamper Guardrail is active; tests must be purely additive.
