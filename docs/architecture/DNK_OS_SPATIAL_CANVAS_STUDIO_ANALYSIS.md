# 🧠 Комплексний Аналіз Дошки Excalidraw: Просторова Агентна ОС DNK OS

## 📌 1. Вступ та Контекст Сесії

За посиланням на Excalidraw-дошку (`#json=j-06b7qCBLiznGffS96A8,RgkJGza0ViJgEMhmaqXtgA`) зафіксована масштабна візія, бенчмарки провідних продуктів світу (CapCut, Google Stitch, Taskade, Open Design) та детальна інженерна формула створення **Spatial Autonomous Operating System (Просторової Агентної ОС)** для DNK OS.

**Ключова мета:**
Створити робочий кабінет розробника/користувача на базі безкінечного node-based полотна, що поєднує принципи вільного простору (Excalidraw/tldraw), точність редагування та шаблони (CapCut / Open Design), простоту компонування (Google Stitch) та структурованість воркфлоу (Taskade Spaces), під керуванням AI-агентів (Герич / Hermes Swarm).

## 🏛️ 2. Чотири Фундаментальні Стовпи Системи

### 🏛️ Стовп 1: Інтелектуальний Брифінг та Агент-Бібліотекар (SCONES Brain)
- **Принцип:** «Користувач проходить початковий брифінг ➔ створюється пам'ять проєкту ➔ агент знає контекст і веде людину».
- **Onboarding Wizard у Launchpad:**
  - Замість громіздких форм — живий адаптивний діалог: «Який продукт запускаємо?», «Хто цільова аудиторія?», «Завантажте референси/логотипи/конкурентів».
- **Агент-Бібліотекар (`dnk_librarian` / SCONES):**
  - Виділяє ізольований простір пам'яті (`workspace` / `tenant`).
  - Екстрактує палітру кольорів, айдентику, Tone of Voice та ключові УТП (USP).
  - Усі наступні генерації автоматично спираються на ці знання.
- **Prompt Co-Pilot (Покращувач промптів):**
  - Перетворює побутове формулювання у вивірену інженерну специфікацію для рендерингу (3D студійний рендер, макро-фокус, колірні акценти в стилі бренду, точні пропорції 9:16).

### 🏛️ Стовп 2: Ментальна Модель (Кабінет Launchpad ➔ Верстак Canvas)
- **Launchpad (`/` або кабінет):**
  - Стратегічний центр управління всіма проєктами (ReBurn, Apex тощо).
  - Каталог готових бізнес-шаблонів («E-Com швидкий старт», «UGC Відео-воронка», «Брендинг з нуля»).
  - Точка старту нових проєктів.
- **Infinite Canvas (`/os?project={id}`):**
  - Робочий верстак, який відкривається **не порожнім**, а з уже розгорнутим стартовим TaskDNA-графом:
    - Нода пам'яті бренду.
    - Нода вітрини магазину.
    - Нода першої медіа-генерації.

### 🏛️ Стовп 3: Human-in-the-Loop & Захист Бюджету (Вартісний Бар'єр)
- **Вирішення головного страху бізнесу:** Неконтрольоване спалювання грошей та токенів.
- **План перед дією:** Жодної «сліпої» генерації важкого відео чи сотень рядків коду — спершу на канвасі відображається легкий драфт/розкадровка/тези.
- **Прозорий розрахунок вартості:** Біля кнопки підтвердження чітко зазначено: *«Це коштуватиме 12 кредитів / ~$0.04»*.
- **Approval Gate:** Реальне списання ресурсів та генерація запускаються **тільки після кліку [Затвердити та виконати]**.

### 🏛️ Стовп 4: Повний 360° Бізнес-Стек + Мультиканальне Керування
- **E-Commerce Ядро (Shopify OS 2.0):** Генерація конверсійних карток, AOV-бандлів, синхронізація через Liquid AST у живий магазин.
- **Медіа-фабрика:** Створення 9:16 роликів із субтитрами та диктором (Remotion), статей для блогу, SEO, постів для соцмереж.
- **CRM & Аналітика:** Воронка продажів, відстеження лідів, аудит конверсій.
- **Telegram Omnichannel Controller:** Мобільний контроль поза робочим місцем. Агент надсилає сповіщення у закриту Telegram-групу з кнопками дій (`[✅ Опублікувати]`, `[🔄 Перегенерувати]`), оновлюючи статус на Канвасі.

   - **Що взято:**
     - Шаблонізація, робота з графічними примітивами та пісочниця для компонентів.

## 🚀 4. Архітектура Ядра (The Core) & SOTA Open-Source Стек

Для забезпечення швидкості **60 FPS** без перевантаження браузера закладено 3 залізні принципи:
1. **Lightweight Proxy Rendering:** На загальному канвасі ноди рендеряться як надшвидкі WebP/SVG/Canvas мокапи; важкі плеєри (Remotion) чи редактори підвантажуються Lazy лише при зумі.
2. **Уніфікований AST (Abstract Syntax Tree):** Спілкування між нодами через структуровані JSON-дерева (Liquid AST, Motion AST, Design AST).
3. **Offloading розрахунків:** Рендеринг відео, ШІ-пайплайни та валідація коду виносяться на FastAPI-бекенд та Web Workers.

### 📊 Матриця SOTA Open-Source рішень:

| Компонент / Завдання | Обране SOTA Рішення | Чому саме воно | Як інтегрується в DNK OS |
|---|---|---|---|
| **Базовий Canvas Скелет** | `@xyflow/react` (React Flow) | 100% нативний React DOM у кожній ноді; робота з вкладками, iframe, формами, чатом | Головний рушій `CanvasEngine.tsx` з 6 живими типами карток |
| **Data-Flow & Розумні Зв'язки** | `bytedance/flowgram.ai` (8.4k ⭐) | Рушій від творців CapCut; вбудована реактивна передача змінних між нодами, авто-трасування без перетинів | Асиміляція логіки розумних конекторів та передачі стану |
| **Стандарт SSOT Полотна** | `JSON Canvas` (jsoncanvas.org / Obsidian) | Відкритий специфікований формат `.canvas` (чистий JSON) | Збереження полотна в Git; агенти нативно читають і мутують граф |
| **Режим Скетчингу (Wireframe)** | `tldraw` (50k+ ⭐) | SOTA freehand векторне малювання | Швидкий скетч маркером ➔ агент зчитує лінії ➔ перетворює в живий React/Liquid UI |
| **Колаборація Користувач-Агент** | `open-canvas` & `CopilotKit` | Selection-aware prompting, Time-travel diffs | Виділення блоку/коду + Cmd+K для точкових правок; відкат історії |
| **Високопродуктивний Стейт** | `Yjs` + `Zustand` + `RBush` | Spatial R-Tree індексація (50k+ елементів), Viewport Culling, CRDT | Усунення затримок при зумі та масштабуванні |
