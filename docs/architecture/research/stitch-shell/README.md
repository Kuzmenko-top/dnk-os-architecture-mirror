# Stitch Canvas Shell Prototype

Цей каталог містить документацію, схеми подій, реєстр стану та карту сумісності для інтерактивного молекулярного полотна Stitch Canvas, розробленого як нативна основа для DNK Canvas Engine.

---

## 🚀 Що вже реально працює (Done & Production-Ready)

1. **Глобальний диспетчер команд (`design.commands.ts`)**:
   - Повноцінний інтерфейс виконання команд з унікальними Command ID та типізованим payload.
   - Підтримка подій локального полотна (`canvas.reset_view`).
2. **Синхронізація станів (State Sync & Control)**:
   - Єдине джерело правди для інструментів полотна: вибір інструменту у `StitchRightToolbar` синхронізований із гарячими клавішами на рівні контейнера полотна.
   - Повністю підтримується скидання масштабу та центрування за допомогою гарячої клавіші `Escape`.
3. **Клієнтські інструменти та Toasts**:
   - Спливаючі сповіщення (toasts) відображають результат запуску команд і зміни інструментів у реальному часі.
   - Автоматичне затухання сповіщень через 3.5 секунди.
4. **Матриця якісних станів (Quality States Matrix)**:
   - Можливість інтерактивного тестування всіх якісних станів панелі логів (`success`, `empty`, `error`, `disabled`, `offline`, `idle`, `loading`) прямо з UI за допомогою перемикача стану.
5. **Інтеграційні тести (Vitest)**:
   - Покриття тестами всіх основних сценаріїв взаємодії (масштабування, вибір інструменту, гарячі клавіші, імітація черги команд). 6 з 6 тестів проходять успішно.

---

## ⚙️ Що є прототипом / чергою (Queued & Prototype)

1. **Генерація контенту Liquid (`design.generate_liquid`)**:
   - При виклику цієї команди (через швидкі кнопки Pills чи текстове поле) статус запиту стає `queued`.
   - UI показує реалістичне прев'ю артефакту зі станом `loading`, яке через 1.5 секунди переходить в `success` і відображає згенерований Liquid-шаблон.
2. **Збирання робочого простору (`design.generate_workspace`)**:
   - Запит стає у чергу (`queued`) та виводить інформаційне сповіщення про очікування з'єднання з оркестратором.
3. **Експорт коду (`canvas.export`)**:
   - Кнопка "Export Code" імітує підготовку та перехід у стан очікування компілятора.

---

## ❌ Чого немає / Поза межами релізу (Missing)

1. **Пряме збереження у базу даних**: Збереження стану полотна вимагає повноцінного узгодження схеми моделей даних DNK DB.
2. **Нативні іконки**: Тулбар відображає літери замість SVG-символів.
3. **Повноцінний Drawing Engine**: Тимчасово реалізовано простіший CSS transform зсуву (pan) та масштабу (zoom). Повноцінний рушій малювання очікує остаточного рішення щодо інтеграції Excalidraw.
