## 🔍 Спостереження (Observation)
У CrewAI Enterprise (screen_002) є механізм "Human-in-the-Loop", який зупиняє виконання агента і запитує текстовий фідбек від користувача через просту веб-форму.

## 🩹 Біль, що вирішується (Pain Point)
Повністю автономні агенти можуть здійснювати небезпечні дії (наприклад, видаляти файли, надсилати неперевірений код на прод або виконувати дорогі API-запити), що веде до фінансових та репутаційних втрат. Проста булева перевірка не захищає від обходу логіки або реверсивних збоїв.

## 🚀 Продуктова ідея для DNK OS
Ми створюємо **Supervisor Approval Gates** (Гейти затвердження супевізором) як двофазну систему безпеки:
* **Developer API (Декоратор):** Спрощений інтерфейс розробника для маркування чутливих функцій.
* **Security Authority (Служба Політик/Гейтів):** Центральний сервіс, що ухвалює рішення та веде криптографічний аудит-лог.

---

## 🛡️ Zero-Regression Gate (Обов'язковий бар'єр)
1. **Концепція Прототипу (Prototype Specification):**
   * Створити базовий контракт `IGateService` в `core/security/contract.py` та декоратор `@security_gate(level="high")` в `core/security/gates.py`. Сервіс повинен валідувати запити на базі конфігурованих політик і вести незмінний лог.
2. **Сценарій Тестування (Test Scenario):**
   * Написати тест, який намагається виконати функцію видалення файлу. Тест має зупинитися, зажадати підтвердження, а при відмові або таймауті — повернути виняток `PermissionError` (fail-closed) без видалення.
3. **Обґрунтування Цінності (Value Justification / ROI):**
   * 100% захист від критичних помилок ШІ, випадкового знищення даних або несанкціонованих фінансових витрат.
