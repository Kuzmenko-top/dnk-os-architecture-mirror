## 📋 Опис таксономії рослин у Task Forest

Система керування завданнями DNK OS використовує органічну 5-рівневу шкалу рослинності (Plant Scale Hierarchy) для структурування всіх проектів, епіків та окремих тасок:

### 🌾 1. Поле (Project_Field — Рівень 1)
- **Призначення**: Масштаб глобального проекту чи великого продуктового релізу (наприклад, розробка повної MVP версії платформи).
- **Зона впливу**: Поєднує всі сектори та підсистеми проекту.

### 🏞️ 2. Сектор (Sector_Zone — Рівень 2)
- **Призначення**: Суб-модуль, крупна підсистема чи технологічний домен (наприклад, `visual_shell` або `dnk_git_research`).
- **Зона впливу**: Поєднує окремі епіки та архітектурні дерева.

### 🌳 3. Дерево (Epic_Tree — Рівень 3)
- **Призначення**: Архітектурний епік або сукупність логічно пов'язаних фіч (наприклад, `tree_cognitive_agent_swarm_factory`).
- **Зона впливу**: Керує набором кущів завдань та виступає точкою збирання звітів (Cycle Reports).

### 🌿 4. Кущ (Feature_Bush — Рівень 4)
- **Призначення**: Конкретна велика фіча або окремий функціональний контур (наприклад, `bush_self_improving_swarm_engine`).
- **Зона впливу**: Поєднує групу окремих квіток-задач та є рівнем виконання Cascade Rollup.

### 🌸 5. Квітка (Task_Flower — Рівень 5)
- **Призначення**: Атомарне інженерне завдання, баг-фікс або розробка конкретного файлу/сервісу (наприклад, розробка окремої функції чи тесту).
- **Зона впливу**: Напряму призначається ройовим агентам та має чітко визначені критерії перевірки (TDD).
