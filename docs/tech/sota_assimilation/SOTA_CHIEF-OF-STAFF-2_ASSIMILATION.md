## 🏛️ 2. Architectural Analysis: The V1 Bloat vs. V2 Subtraction

### The Failure Mode of Version 1
- **File bloat**: Vault expanded to >5,000 files.
- **Cognitive overhead**: Mornings started by fixing hooks, synchronizing indices, and debugging broken memory files rather than doing founder work.
- **Silent failures**: Jobs broke without alerts (one stayed broken for 11 days).
- **Violation of Law 10**: The assistant machine became its own high-overhead engineering project.

### The Subtraction Rebuild (V2)
- Rebuilt around a single question: *"If this vanished tonight, would I even notice?"*
- Any script, prompt, or memory layer failing that test was deleted, not repaired or monitored.
- Established the **Subtraction Over Surveillance** coda: do not monitor unneeded things; delete them.

## 📐 3. The 4-Part Chair Anatomy
Every role in the personal C-Suite follows an invariant 4-part structure:
1. **Skill File**: Thin operating manual. Concrete procedural steps. Stateless. Optimized for execution by fast/cost-effective models.
2. **Source File**: Current dynamic state. Open loops, recent rulings, active decisions, next physical action. High update frequency.
3. **Parts / Research Folder**: Domain assets, reference documents, schemas, and ongoing research.
4. **Archive Folder**: Dated write-once session transcripts (`YYYY-MM-DD Title.md`). Never auto-loaded into context (preserves token budget and prevents context rot).

### Key Architectural Roles Shipped:
- **Planner**: Time, calendar, sprint cadence, daily rhythms.
- **Career Coach**: Long-term strategy, market positioning, skill mastery.
- **Health**: Physical and mental energy, sleep, cognitive capacity.
- **Money**: Financial runway, revenue streams, obligations.
- **Physical Plant**: The **inward-facing chair** that manages harness config, prompt wiring, cron heartbeats, and vault file structure.
