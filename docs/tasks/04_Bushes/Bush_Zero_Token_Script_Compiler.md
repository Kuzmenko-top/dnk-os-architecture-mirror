# 🌿 Кущ: Zero Token Script Compiler

## 📋 Опис куща фіч
Компіляція повторюваних рутинних сценаріїв у локальні легковажні скрипти автоматизації для запуску безпосередньо через інтерфейс командного рядка (CLI) або шелл. Це дозволяє виконувати регулярні завдання за 0$ LLM токенів, унеможливлюючи зайві витрати.
