# 📱 Посібник Користувача: DNK OS v2 Core MVP

Ласкаво просимо до **DNK OS v2 Core MVP**! Цей документ містить покрокові інструкції щодо налаштування, запуску та повсякденного використання системного Ядра.

## 🚀 Швидкий Старт

Для початку переконайся, що у твоєму робочому середовищі встановлено `uv` та необхідні залежності.

### 1. Запуск Юніт-Тестів
Щоб перевірити працездатність усіх 5 системних двигунів, виконай команду у терміналі:
```bash
uv run pytest core/tests/
```
Всі 18 тестів мають пройти успішно (зелений статус).

## ⚙️ Покрокові Інструкції з Використання

### 🔑 1. Авторизація та Керування Сесіями (`auth_engine`)
Двигун авторизації забезпечує перевірку твоїх дій та безпечне збереження активних сесій.
*   **Як авторизуватися**: Метод `verify_maksym("погоджую")` звіряє фразу з безпечним хешем.
*   **Створення сесії**: При кожній успішній дії створюється сесія, що зберігається в зашифрованому файлі `DNK OS/sessions/session_registry.json` з обмеженими правами доступу (`0600`).
*   **Приховування секретів**: Будь-які токени чи ключі автоматично маскуються методом `redact_secret("sk-proj-...")` у логах.

### 🎨 2. Моніторинг Завдань на Вузловому Полотні (`canvas_engine`)
Візуальне полотно дозволяє контролювати стан агентів, завдань та документів.
*   **Кольорові стани вузлів**:
    - 🟢 **Зелений (`🟢 Done`)**: Завдання успішно виконано.
    - 🔵 **Синій (`🔵 Executing`)**: Агент зараз працює.
    - 🔴 **Червоний (`🔴 Blocked`)**: Виконання заблоковано через помилку чи очікування погодження.
    - 🔘 **Сірий (`🔘 Queued`)**: Завдання знаходиться в черзі.
*   **Запобігання циклічним блокуванням**: Система автоматично виявляє кругові залежності (цикли) перед запуском, не дозволяючи системі зависнути.

### 🛡️ 3. Безпечне Виконання та Авто-Відкат (`hermes_runtime`)
Цей компонент захищає твій код від зламу під час експериментів.
*   **Dry-Run (Попередній План)**: Перед будь-якою зміною коду система покаже тобі звіт про те, які файли будуть змінені.
*   **2-Етапне Підтвердження**: Деструктивні операції генерують запит на погодження. Тобі потрібно відправити команду `approve_destructive_action` з кодовою фразою `"погоджую"`.
*   **Автоматичний Відкат (Rollback)**: Якщо тести або перевірки гігієни падають **2 рази поспіль**, двигун скасовує всі зміни у файлах, повертає їх до початкового стану та блокує виконання, захищаючи систему від деградації.

### 📊 4. Фінансовий Контроль та Токени (`accounting_engine`)
Контролюй витрати на ШІ у режимі реального часу.
*   **Телеметрія**: Кожна операція логує кількість вхідних/вихідних токенів, тривалість у мілісекундах та точну ціну в USD.
*   **Звіти ROI**: Отримуй агреговані звіти про зекономлені кошти та загальний успіх системи за допомогою команди `accounting_get_report`.
