# 🎬 Відеопосібники та навчальні матеріали DNK OS

Офіційний каталог інтерактивних відеогідів для нових користувачів та інженерів DNK OS.

## 📺 Каталог відеоуроків

### 1. DNK OS за 5 хвилин (Огляд екосистеми)
- **Тривалість**: 5:32
- **Рівень**: Початковий
- **Посилання на відео**: `https://www.youtube.com/watch?v=dnk-os-5min-overview`
- **Корисні розділи**: [Швидкий старт](./GETTING_STARTED.md#1-швидкий-старт-5-хвилин)

#### Таймкоди (Timestamps)
- `0:00` - Вступ: Що таке DNK OS і чому це майбутнє автономних агентів
- `1:15` - Огляд Launchpad: Проєкти, шаблони бізнесу та сховище SCONES
- `2:40` - Перше знайомство з мультиагентним роєм (14 агентів)
- `4:05` - Запуск автономного конвеєра створення продукту
- `5:10` - Підсумок та подальші кроки

#### Текстова транскрипція (Transcript)
> **[0:00]** Привіт! Ласкаво просимо до знайомства з DNK OS. DNK OS — це гіперконвергентна автономна операційна система, яка об'єднує 14 спеціалізованих AI-агентів, візуальне середовище Canvas та єдину систему довготривалої пам'яті SCONES.
> **[1:15]** На головному екрані Launchpad ви бачите поточні активні проєкти, шаблони для миттєвого старту та візуальний оглядач рою агентів.
> **[2:40]** Кожен агент має власну спеціалізацію: від архітектора та верстальника інтерфейсів до фінансового директора та відеомейкера.
> **[4:05]** Ви можете запустити повний цикл створення продукту буквально в один клік — система генерує стор на Shopify, медіа-креативи в Remotion та підключає бізнес-аналітику.
> **[5:10]** Переходьте до наступного уроку, щоб створити своє перше робоче полотно!

### 2. Створення першого Canvas (Практичний воркшоп)
- **Тривалість**: 8:15
- **Рівень**: Практичний / Базовий
- **Посилання на відео**: `https://www.youtube.com/watch?v=dnk-os-first-canvas`
- **Корисні розділи**: [Створення Canvas](./GETTING_STARTED.md#2-перші-кроки-створення-першого-canvas)

#### Таймкоди (Timestamps)
- `0:00` - Створення проєкту та вибір шаблону
- `1:50` - Робота з вузлами полотна (Nodes, Sticky Notes, Agent Tasks)
- `3:30` - Зв'язування вузлів у граф залежностей TaskDNA
- `5:15` - Виклик генератора (Action Engine) та отримання результату
- `7:00` - Експорт полотна та синхронізація з Obsidian Vault
- `8:00` - Завершення воркшопу

#### Текстова транскрипція (Transcript)
> **[0:00]** Сьогодні ми створимо перше інтерактивне полотно. Натискаємо кнопку "+ Нове полотно" на Launchpad.
> **[1:50]** На робочому полі створюємо ноди завдань: двічі клікаємо для тексту або тиснемо Space для командного рядка агентів.
> **[3:30]** Коли ноди з'єднані лініями залежності, система створює ациклічний граф (DAG).
> **[5:15]** Натискаємо "Generate" — агент gerych_builder в реальному часі створює код інтерфейсу.
> **[7:00]** Готовий граф можна зберегти або автоматично експортувати у вашу базу знань Obsidian.

### 3. Advanced Features & Swarm Orchestration
- **Тривалість**: 12:45
- **Рівень**: Просунутий / Інженерний
- **Посилання на відео**: `https://www.youtube.com/watch?v=dnk-os-swarm-deep-dive`
- **Корисні розділи**: [Просунуті можливості](./GETTING_STARTED.md#3-просунуті-можливості-advanced-features)

#### Таймкоди (Timestamps)
- `0:00` - Вступ до протоколу Zero-Waste High-Velocity
- `2:10` - Автономний Triage (SOLO vs SWARM_PARALLEL vs SWARM_SEQUENTIAL)
- `4:45` - Паралельна робота агентів через dnk_swarm_parallel
- `7:30` - Двостороння синхронізація Canvas з WebSocket шлюзом
- `9:50` - Інтеграція з Remotion для створення відео
- `11:40` - Контроль бюджету токенів та SpendGuard
- `12:30` - Висновки

#### Текстова транскрипція (Transcript)
> **[0:00]** У цьому глибокому зануренні ми розглянемо архітектуру оркестрації рою DNK OS.
> **[2:10]** Алгоритм Triage аналізує складність за формулою C = F + 2D + 3S та миттєво обирає режим виконання.
> **[4:45]** Завдяки паралельному виконанню, завдання розподіляються між builder, shopify, dev_fullstack та auditor за мілісекунди.
> **[7:30]** Події транслюються через WebSocket шину, тому зміни від різних агентів відображаються на екрані без затримок.
> **[9:50]** Модуль Remotion перетворює React-компоненти у готові MP4-відеоролики для TikTok та Instagram.
> **[11:40]** Захисний шлюз SpendGuard гарантує, що жодне завдання не перевищить ліміти витрат або глибини рекурсії.
