# 🧠 Vibe-Coder & Founder Core Architecture Protocol (SOTA September 2026)

## 1. Role Division & Mental Model
For founders and web-coders (HTML/CSS, visual UI, product UX) who do not write backend code or low-level algorithms:

| Role | Responsibility | Artifacts Created |
| :--- | :--- | :--- |
| **Founder / Vibe-Coder** | Visionary, UX Architect, Product Logic, Input/Output Contracts | Screen designs, user flow descriptions, API schema contracts |
| **Gerych Prime & Swarm** | Autonomous Engineering, Subtraction Rebuild, Testing, Tooling | Python/FastAPI code, React components, test suites, git commits |

### The 4 Core Primitives of an Agentic Operating System
1. **Agent Runtime (Brain)**:
   - Receives goals, decomposes them into atomic DAG slices (`dnk_decompose_task_dna`).
   - Dispatches work to specialized domain workers (`dnk_dev_fullstack`, `gerych_builder`, `gerych_auditor`).
2. **Tool Execution Matrix (Hands)**:
   - Real-world interaction: file reading/writing, terminal execution, browser navigation, code execution.
   - Strict containment and permission-safe operations.
3. **Cognitive Memory Tiering (Memory)**:
   - L1 Fast Context: active session state and working buffers.
   - L2 Persistent Knowledge: SCONES episodic memory and Error Distillation database (`dnk_query_error_solutions`).
4. **Autonomous Quality Gates (Safety Shield)**:
   - Pre-commit verification (`verify_all.sh`).
   - Adversarial review (Auditor ⚔️ vs Builder 🛡️) to ensure zero broken builds before founder review.
