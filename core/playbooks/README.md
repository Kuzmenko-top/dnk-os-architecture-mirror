# 🛠️ DNK OS Playbooks: Script-First Execution Standard

**DNK OS Playbooks** — це каталог системного досвіду, отриманого за 6 місяців інтенсивного R&D, та бібліотека **автономних скриптів виконання**.

---

## ⚡ Принцип "Script-First Execution"

1. **Не засмічуйте контекст LLM**: Замість того, щоб пояснювати агентам 10-кроковий алгоритм очистки, верифікації чи збірки текстом у промптах, ми реалізуємо його у вигляді детермінованого Python-скрипта у папочці `scripts/`.
2. **Виконання у 1 рядок**: Агент замість читання 500 рядків інструкції просто виконує скрипт:
   ```bash
   PYTHONPATH=. uv run python core/playbooks/scripts/run_system_health_audit.py
   ```
3. **100% Точність та Токен-Екологія**: Скрипт виконується локально за мілісекунди без витрати токенів LLM, без галюцинацій та без помилок.

---

## 📚 Структура Каталогу

- **`PLAYBOOK_INDEX.md`**: Зведений каталог проблем, рішень та плейбуків за 6 місяців.
- **`scripts/`**: Автономні Python-скрипти для автоматизації рутини розробника.
- **`lessons_learned/`**: Офіційні уроки системної пам'яті (Lessons Learned).
