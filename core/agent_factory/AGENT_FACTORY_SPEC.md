# 🤖 Специфікація Агентної Фабрики DNK OS

Цей документ визначає стандартизований процес створення, адаптації та підключення нових AI-агентів у команду **DNK OS**.

---

## 📋 Стандартні Компоненти Нового Агента

Кожен агент розміщується у папці `core/agent_factory/agents/<agent_name>/`:

1. **`SOUL.md`**:
   - Описує ідентичність, роль, поведінкові обмеження та i-have-adhd протокол спілкування.
2. **`MANIFEST.yaml`**:
   - Описує ID агента, його доступи, навички, дозволені інструменти CLI та канали зв'язку.
3. **`skills/`**:
   - Локальні папки навичок, доступні цьому конкретному агенту.
4. **`memory/`**:
   - `short_term_memory.json`: поточні контексти виконання задач.
   - `long_term_reflections.md`: збережені системні уроки та висновки.
