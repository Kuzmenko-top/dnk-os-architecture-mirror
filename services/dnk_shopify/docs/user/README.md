# 🛍️ DNK Shopify Agentic Service

Це документація кінцевого користувача для сервісу **dnk_shopify** у складі DNK OS.

## 🌟 Можливості сервісу
1. **Автоматична розробка та аудит тем:** Розширюйте канонічну тему **DNK Ecom**, додаючи сучасні та конверсійні секції (Liquid + JSON Schema).
2. **Побудова воронки квізів (Quiz Creator):** Автоматично генеруйте квізи підбору товарів для підвищення залученості покупців.
3. **ШІ-Генерація рекламного контенту:** Створюйте PDP, Landing Pages, Advertorials та Listicles безпосередньо з вашої бази знань.
4. **Контроль відхилень (Drift Control):** Жодна зміна теми не зламає сумісність із Shopify Theme Editor завдяки вбудованому валідатору схем.

## 🛠️ Як почати роботу
Сервіс автоматично налаштований та готовий до інтеграції у ваш CLI-інтерфейс.

```bash
# Перейдіть до папки сервісу
cd services/dnk_shopify

# Запуск оркестратора або перевірки
python3 src/orchestrator.py
```
